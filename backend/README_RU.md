# Серверная интеграция LESKOV Android 3.3.1

На Linux-сервере `/var/www/lesv.online` изменения применены 4 ноября 2026 года.
Копии исходных файлов находятся вне web-root: `/home/lesvonline/leskov-backups/`.

Для другого сервера сначала проверьте `patch --dry-run -p1 < site-integration.patch`
в корне сайта. Затем примените патч и скопируйте `mobile_push.php` и
`includes/mobile_push.php` в соответствующие каталоги сайта. Не заменяйте весь
сайт этим каталогом. Требуются PHP curl, openssl и MySQL; таблица устройств
создаётся при первом обращении. Неавторизованные запросы получают 401;
изменения регистрации требуют действующий CSRF-токен сессии.

Настроено:
- регистрация/переназначение токена текущему пользователю и удаление при выходе;
- обновление регистрации Android раз в сутки;
- FCM HTTP v1 для сообщений и социальных событий с проверкой настроек push;
- уведомления и отмена уведомлений для обоих механизмов звонков;
- короткий TTL звонков, игнорирование просроченных и отменённых вызовов в Android;
- окна обоих механизмов звонков (messages и profile) в feed, discover, search, gifts, notifications, saved, user, secret;
- закрытие окна звонка из profile после отмены собеседником;
- отсутствие боковой панели профиля в общей ленте Android.

Для реальной отправки отсутствует серверный ключ проекта `leskov-b3863`.
Поместите JSON сервисной учётной записи **вне каталога сайта**:
`/etc/leskov/firebase-service-account.json`, с чтением только для администратора
и PHP-FPM (например root:www-data, 0640; каталог 0750).
Либо задайте PHP-FPM переменную `GOOGLE_APPLICATION_CREDENTIALS`.
Учётной записи нужны права `cloudmessaging.messages.create`, например роль
`roles/firebasecloudmessaging.admin`; Firebase Cloud Messaging API (v1) должна
быть включена в Google Cloud. Ключ не включать в GitHub, APK или переписку.

Оставшиеся проверки требуют доступа к Firebase Console и телефона:
права учётной записи, состояние API, отправка на настоящий FCM-токен,
получение в фоне/на заблокированном экране и принятие WebRTC-звонка.
Скриншоты обзорной страницы и успешная сборка сами по себе доставку не подтверждают.
