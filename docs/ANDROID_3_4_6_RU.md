# LESKOV Android 3.4.6 — повторная доводка интерфейса

База: 3.4.5 с CI hotfix. versionCode 14, прежние applicationId, minSdk 26, targetSdk 36, сертификат и разрешения. Кандидат в релиз, не готовый подписанный APK.

- Обычные диалоги: сокращённое описание (одна строка, полное описание на профиле), компактные аватар, бейджи, действия и поле ввода. Почти вся ширина WebView принадлежит переписке. Список и переписка имеют собственные области прокрутки. Гирлянда размещена над контентом, её высота учтена при уменьшении окна клавиатурой. Никаких изменений серверной логики чатов.
- Фото/файлы: системный ACTION_OPEN_DOCUMENT с фильтром MIME и множественным выбором только для соответствующего поля. Обрабатываются Intent.data и ClipData, остаются проверки HTTPS-источника, поколения документа, владельца URI и явного read grant. Никаких дополнительных разрешений. Добавлен счётчик выбранных фото и отмена выбора; реальная отправка остаётся в штатной форме сайта. Отмена выбора не считается отправкой. Сообщение о небезопасном или пустом результате выбора показывается явно.
- Выход: один AlertDialog сохраняет исходный текст и размеры, на месте кнопки подтверждения индикатор до серверного результата. Серверный POST и проверка 401 не изменены.
- Гость: Главная, Поиск, Ещё. В Ещё нет настроек аккаунта и уведомлений. После входа все шесть вкладок и оба пункта возвращаются. Индексы вкладок не меняются.
- Premium: фон покрывает WebView, диалог ограничен высотой экрана, но короткий контент не растягивается искусственно; единственная прокручиваемая область. Аудиоэлемент не пересоздаётся.

## Приёмка

1. CI должен пройти без ошибок, затем отдельно запустить signed release candidate из main. Сравнить SHA-256 APK/AAB, package, versionCode 14, сертификат с 3.4.5, отчёт OSV. Проверить новый APK VirusTotal и Play Protect. Не использовать отчёты предыдущих APK.
2. Установить подписанную 3.4.6 поверх 3.4.5 без удаления приложения. Проверить вход и выход (подтвердить, отменить, потеря сети), отсутствие второго окна, возврат гостевой панели из трёх вкладок и восстановление шести после входа. Пройти RU/ET/EN, обе темы.
3. Проверить список диалогов и переписку с длинным именем, био, бейджами, 50+ сообщениями, новым сообщением и клавиатурой. Проверить зимний режим включён/выключен, прокрутку, кнопки, отсутствие перекрытий.
4. Выбрать одно фото, четыре фото, отменить, убрать выбранное, отправить и проверить доставку на втором аккаунте. Отдельно выбрать PDF и разрешённые аудио/видео. При отказе URI или ошибке сети пользователь должен увидеть причину; не считать выбор успешной отправкой. Проверить секретные чаты, голосовые, видеокружки, звонки, FCM.
5. Premium: 0/1/4/20 треков, прокрутка до конца, закрытие, переключение вкладок, фоновое воспроизведение. Проверить на реальном Samsung и другом Android.

Локальные тесты используют Chromium и синтетический DOM, в том числе с CSS из предоставленного архива сайта. Они не подтверждают фактическую доставку вложений или работу Android Documents UI. Kotlin/Compose тесты должны быть выполнены в GitHub Actions (в среде подготовки патча Android SDK отсутствует).
