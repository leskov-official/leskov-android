# LESKOV Android 3.4.4 — безопасность и подготовка финального релиза

Версия 3.4.4, versionCode 12. Сохранены `com.aistudio.leskov.musix`, Android 8.0+, target/compile SDK 36, Gradle 9.3.1, существующий релизный сертификат, имена GitHub Secrets и Firebase-проект. Это кандидат на финальный релиз, а не утверждение о завершённой проверке на устройствах. Перед сборкой проверьте, что versionCode 12 не использован в иных выпусках.

## Что изменилось

* WebView: выбор файлов принимает только `content://` от найденного внешнего провайдера с явным разрешением чтения от Android. URI собственного приложения, общего UID, неизвестного провайдера и URI другого профиля (`user@authority`) отклоняются. Некорректный набор из нескольких файлов отклоняется целиком. Старая операция выбора не может передать результат после новой загрузки документа/смены URL. Не добавлены разрешения хранилища и не отменена защита Android. Используются исходные фильтры WebChromeClient; корректность конкретных галерей и облачных менеджеров следует подтвердить на устройствах. `allowContentAccess` сохранён для совместимости системных вложений; сервер обязан проверять содержимое, размеры и права загрузки. Уровень доверия сайта и его скриптов требует отдельной проверки.
* Резервное копирование: исключены основные и device-protected области хранения в старых/новых XML; cloud-backup и device-transfer исключают локальные данные. Данные на сервере не удаляются. Реальное поведение переноса зависит от ОС/производителя и проверяется отдельно.
* FCM: проверка корректного клиента Firebase при сборке, сброс устаревшего состояния готовности при ошибке токена, диагностическая категория исключения без токена/пароля в собственных логах. Публикация состояния ограничена доверенной страницей.
* CI: обновлены Node 24 Actions, PR CI не загружает Firebase secret штатным шагом; добавлены проверки безопасности, выгрузка транзитивных Maven runtime-зависимостей и OSV. При совпадении с advisory или незавершённом запросе подписанная сборка останавливается; артефакт аудита доступен отдельно. Проверка AAB дополняет прежнюю проверку APK. Публикации автоматически нет.
* Диалоги: изменения 3.4.3 сохранены; проверены сценарии списка, поиска друзей, переписки и уменьшенного экрана клавиатуры в Chromium. Без подтверждённого нового дефекта CSS не переписывался.

## Firebase Installations — HTTP 400

В отчёте VirusTotal 3.4.3 запрос POST на Firebase Installations проекта `leskov-b3863` вернул 400. Это наблюдение в песочнице, не доказательство ошибки на всех устройствах. Без тела ответа и доступа к Firebase Console точная причина неизвестна.

1. Откройте Firebase Console → Project settings → Your apps → Android. Убедитесь, что выбран именно `com.aistudio.leskov.musix`, проект `leskov-b3863` и правильный App ID. Добавьте SHA-1/SHA-256 **существующего** релизного сертификата, если не добавлены. Не создавайте другой ключ. Отпечатки получаются `keytool -list -v -keystore ~/.leskov-signing/leskov-release.p12 -alias leskov` (пароль вводится локально).
2. Проверьте ограничения API-ключа и доступность Firebase Installations API в Google Cloud Console. При Android application restriction должны быть корректные package/SHA-1; не отключайте ограничения без необходимости и не расширяйте права ключа на несвязанные API. См. https://firebase.google.com/docs/projects/api-keys и https://firebase.google.com/support/guides/init-options.
3. Если конфигурация действительно изменилась или неверна, скачайте свежий `google-services.json` из своего проекта и замените только `FIREBASE_ANDROID_CONFIG_BASE64` через GitHub CLI (путь к локальному файлу укажите самостоятельно): `base64 -w 0 /path/to/google-services.json | gh secret set FIREBASE_ANDROID_CONFIG_BASE64 --repo leskov-official/leskov-android`. Не публикуйте JSON или токены в чате. Остальные Secrets не трогайте. Если данные правильны — менять их не требуется.
4. После проверки безопасности и на разрешённом тестовом устройстве с включённым Play Protect откройте приложение, войдите в тестовый аккаунт, разрешите уведомления. Из локального журнала `adb logcat -d -s LeskovFCM FirebaseInstallations FirebaseMessaging` смотрите только категории ошибок; перед передачей журналов удалите токены, персональные данные и ключи. Проверьте фактическую доставку сообщения в foreground/background/после обычного закрытия, не путайте закрытие Activity с принудительной остановкой через настройки ОС.
5. Если Play Protect блокирует легитимное приложение после аудита, не отключайте защиту, не меняйте package ID или ключ для обхода, не публикуйте APK. Официальная апелляция: https://support.google.com/googleplay/android-developer/contact/protectappeals.

## Выпуск

После CI и проверки PR объедините изменения с main. Запустите `gh workflow run release.yml --ref main --repo leskov-official/leskov-android` только из проверенного main. Выпуск должен содержать LESKOV-3.4.4.apk/.aab, отчёты подписей, SHA256SUMS.txt, apk-info.txt, source-commit.txt, release-dependencies.tsv и osv-report.json. OSV покрывает только известные записи базы по Maven-модулям, а не весь код и не все уязвимости. Зависимости с найденными уязвимостями нужно расследовать и безопасно обновить, затем повторить проверки. Не удаляйте проверку ради успешного CI.

Сверьте подпись/хеш, проверьте новый APK в VirusTotal (включая Behavior) и пройдите RELEASE_CHECKLIST_RU.md. Отчёт 0/60 относится только к 3.4.3; для 3.4.4 нужен собственный отчёт. После допуска вручную создайте GitHub Release v3.4.4 и загрузите тот же проверенный файл в админку сайта. До этого публичная раздача выключена. Если на телефоне установлен старый debug APK, у него иной сертификат; обновление поверх него не поддерживается без совместимой подписи. Не удаляйте приложение без оценки потери локальных данных.

## Ограничения

Патч основан на исходном архиве и применённом патче 3.4.3, а не на непосредственном доступе к текущему GitHub или Firebase Console. Локальные Python/Node/PHP/Chromium тесты не заменяют Gradle/Android lint, полноценное тестирование APK и аудит сайта. Ключ, пароли и конфигурация Firebase в архив не входят. Не выдавайте статус «безопасно» на основании сборки или подписи.
