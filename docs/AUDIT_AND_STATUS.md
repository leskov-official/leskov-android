# LESKOV Android — аудит экспортированного проекта

Источник: загруженный архив `leskov.zip` (содержал полный Android/Kotlin-проект и результаты прерванной генерации Google AI Studio). Проверены AndroidManifest, Gradle, ViewModel, MainActivity, MediaService, WebView, Firebase-классы и оригинальный серверный JS/PHP из ранее предоставленного архива сайта.

| Приоритет | Факт | Исправление / статус |
|---|---|---|
| P0 | `google-services.json` содержал заведомо поддельный project_number/API key. | Удалён; Gradle применяет Google Services только с настоящим файлом. Сервисная конфигурация Firebase владельца всё ещё необходима. |
| P0 | `LeskovMediaService.kt` использовал необъявленную переменную `audioManager`. | Исправлено в исходниках (удалена неиспользуемая строка). Kotlin/Gradle сборку требуется выполнить в Android Studio. |
| P0 | Клиент отправлял токен на недоказанные `profile.php?ajax=register_fcm_token` URL без доказательства серверной авторизации. | Отключена небезопасная отправка. Требуется серверный контракт и FCM HTTP v1. |
| P0 | Исходящий звонок: JS monkey-patch всех `getUserMedia`, остановка всех tracks каждые 500 мс, даже когда UI ещё не перешёл в active. | Удалён вредоносный перехват. Состояние звонка снова принадлежит серверному `scripts/calls.js`. |

| P1 | JS объявлял музыку paused в период загрузки, не учитывал `playing`/`loadeddata`/`error`. | Улучшено обнаружение состояния и корректная синхронизация в нативном уведомлении. |

| P1 | `addJavascriptInterface` доступен скриптам в подфреймах. | Заменён на ограниченный по HTTPS origin и main-frame WebMessageListener. Добавлена библиотека AndroidX WebKit. |

| P1 | Нативный FCM default small icon не был задан на Manifest уровне. | Задан белый векторный значок и системный канал. |

| P2 | Содержимое Google AI Studio включало сгенерированные TXT/PNG и примеры Gemini API, не нужные в Android Studio. | Убраны ненужные AI-артефакты и неиспользуемые библиотеки. |

## Не подтверждено, потому что среда сборки/серверные ресурсы недоступны

- **APK:** Android SDK/Gradle в текущем контейнере отсутствуют, `assembleDebug`, instrumentation, UIAutomator и физические тесты не выполнялись.
- **Push:** реального Firebase-проекта, регистрационного бэкенда и FCM server sender нет; никакой тестовый remote push не отправлялся.
- **Фоновая музыка:** HTML5 audio не переживёт полную загрузку PHP-страницы без выделенного Media3 stream owner; сервис пока только наблюдатель и уведомления.
- **Звонки:** реальная приёмка/отклонение и Bluetooth/камера требуют минимум два аккаунта, два устройства и интеграцию звонков на сервере.
- **Google Play:** подписанный AAB, Data Safety, удаление аккаунта, отчёт о модерации UGC и политика цифровых покупок отдельно не проверены.

## Статические проверки в этой сессии

- XML из AndroidManifest и ресурсов успешно разобраны XML-парсером.
- JS, внедряемый из Kotlin в WebView, проверен через `node --check`.
- Поддельного Firebase-файла и заведомо вымышленного отправления FCM token в проекте больше нет.

Это **исправленный исходный код для дальнейшей сборки**, а не доказательство готового Play-Store продукта.
