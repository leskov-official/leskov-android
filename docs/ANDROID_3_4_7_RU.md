# LESKOV Android 3.4.7 / versionCode 15 — release candidate

- Диалоги используют оригинальную адаптивную верстку сайта, без Android-only закрепления панелей, принудительного скрытия списка, изменения размеров гирлянды и переноса плавающей кнопки плеера. Остальные страницы сохраняют прежние стили приложения.
- Новые обычные push-сообщения: прямой адрес собеседника, имя, текст и фактический аватар при доступности. Секретные переписки не раскрываются. На заблокированном экране действуют настройки конфиденциальности ОС.
- Системный медиаплеер получает оригинальный цветной логотип в metadata и монохромный знак в smallIcon; Android/One UI решают, как именно его показывать.
- Для зарегистрированного текущего аккаунта меню «Ещё» открывает Центр уведомлений, иначе оставляет подключение уведомлений. Гостевой режим не меняется.
- Android сохраняет все уникальные URI из системного выбора; ограничения на content URI, владельца и read grant не ослаблены. Требуется отдельный PHP/JS-патч сайта для формирования push и проверки всех фото.

- При подтверждённом выходе или завершении сессии нижняя панель, меню и системные полосы возвращаются к тёмной нативной теме; гостевые сообщения о светлой теме игнорируются. При неудачном выходе тема аккаунта сохраняется. После входа применяется тема текущего пользователя. Настройки сайта не перезаписываются.

- Установщик, обычный и круглый значки приложения используют оригинальный PNG 512×512 из `images/icon-512x512.png` сайта без изменения изображения. Устаревшие адаптивные слои больше не назначены в манифесте. Android/One UI могут масштабировать, маскировать или обрамлять значок, а при обновлении могут показывать значок уже установленной версии. Проверить чистую установку и обновление, не удаляя рабочий профиль ради проверки.

## Приёмка
Сначала CI на ветке, затем merge, подписанный кандидат, SHA-256, сертификат прежнего релиза, OSV, VirusTotal и Play Protect. На тестовом аккаунте проверить две темы, зимний режим, список и прокрутку диалога, клавиатуру, фото 1/2/5/10, большой пакет/ошибку и повтор, файл PDF, секретные чаты, пуш при открытом/закрытом приложении, профиль с аватаром и без него, гостя, регистрацию/отзыв разрешения, музыку в фоне. Не публиковать до приёмки. APK 3.4.6 и результаты его проверки не заменяют проверки 3.4.7.
