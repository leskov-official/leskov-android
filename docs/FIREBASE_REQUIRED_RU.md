# Настройка реальных Android Push для LESKOV

В исходниках намеренно нет вымышленного `google-services.json`. Пока Firebase не настроен, уведомления о сообщениях/звонках **не доставляются через FCM**, независимо от выданного Android-разрешения.

1. В Firebase Console создайте проект и зарегистрируйте Android-приложение с ТОЧНЫМ идентификатором `com.aistudio.leskov.musix`.
2. Скачайте настоящий `google-services.json` и **не коммитьте его в публичный репозиторий**.
3. В локальной Linux-среде с доступом к этому файлу: `base64 -w0 /путь/google-services.json`; результат вставьте только в GitHub → Repository → Settings → Secrets and variables → Actions → New repository secret с именем `FIREBASE_ANDROID_CONFIG_BASE64`. Не отправляйте значение в чате.
4. Для доставки событий с сервера PHP требуется реальный backend FCM HTTP v1 с сервисной учётной записью *только на сервере*, регистрацией устройства в `mobile_push.php` и вызовами отправки при появлении сообщений, комментариев, реакций и звонков. Детали контракта в `docs/BACKEND_FCM_CONTRACT.md`.
5. Проверьте, что серверный endpoint действительно доступен с авторизованной сессией, а токен зарегистрирован. После этого отправьте тестовое уведомление при открытом приложении, в фоне, с закрытой Activity и при заблокированном экране. Отдельно проверьте входящий вызов и его подтверждение на сервере.
6. Простая активация `POST_NOTIFICATIONS` или Web Push в PHP-сайте сама по себе **не делает нативный FCM рабочим**.

Приложение должно честно показывать статус отсутствующей конфигурации до её добавления.
