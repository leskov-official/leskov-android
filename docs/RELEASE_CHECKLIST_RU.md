# LESKOV — приёмочный тест-план перед публикацией

Для каждого сценария запишите дату, модель устройства, версию Android, лог, PASS/FAIL/BLOCKED. Не ставьте PASS по факту компиляции.

## Воспроизведение

- [ ] На главной выберите общедоступный трек, Play запускает **слышимое** воспроизведение без мгновенной паузы.
- [ ] Через 60 секунд звук продолжает играть, прогресс растёт.
- [ ] Перейдите Главная → Лента → Поиск → Профиль → Назад. Трек не перезапускается с нуля.
- [ ] Сверните приложение, заблокируйте экран на 2 минуты. Уведомление Media3 показывает правильный трек и работающие Play/Pause.
- [ ] Наушники отключены: воспроизведение останавливается без нежелательной автозагрузки.
- [ ] Новый трек с сайта останавливает старый Media3-поток; два потока не играют одновременно.
- [ ] Премиум-режим, плейлист и приватные URL не обходят серверную авторизацию и выполняются только при наличии прав.

## Авторизация и навигация

- [ ] Гость открывает главную, поиск и «Ещё», но не может ставить лайки, публиковать или писать сообщения.
- [ ] Вход и регистрация открываются с первого нажатия, возвращают в запрошенный раздел.
- [ ] Профиль показывает все разделы до самого низа без обрезания нижним меню.
- [ ] Выбор RU / ET / EN синхронизируется по сайту и Android-панели и остаётся после перезапуска.
- [ ] Вход, выход и повторный вход не ломают куки и текущую сессию.
- [ ] Условия, политика, поддержка `info@lesv.info` действуют.

## Push и звонки

- [ ] Приложение инициализирует Firebase с настоящим проектом; не возникает `FirebaseApp initialization unsuccessful`.
- [ ] После входа FCM-токен зарегистрирован в `mobile_push_tokens` через `mobile_push.php`, без передачи `user_id` клиентом.
- [ ] Входящее сообщение и комментарий приходят при открытом приложении, в фоне и при обычном закрытии Activity.
- [ ] При выходе FCM-токен отвязан. Новый пользователь на том же устройстве не получает чужие уведомления.
- [ ] Входящий звонок показывает дозвон; принятие и отклонение выполняются через серверный `call_id`, не просто открывают экран.
- [ ] Вызов между двумя аккаунтами: аудио, видео, выключение микрофона, завершение, повторный звонок.
- [ ] Иконка пуша читаема на светлой и тёмной теме и на Android 13+ есть разрешение уведомлений.

## Качество, безопасность и выпуск

- [ ] Gradle `testDebugUnitTest`, `lintDebug`, `assembleDebug`, release bundle выполняются без ошибок.
- [ ] Нет повторяющихся `FATAL EXCEPTION`, `E/AudioManager`, `E/ExoPlayer`, `FirebaseApp initialization unsuccessful` в сценариях выше.
- [ ] WebView блокирует посторонние схемы, HTTPS-политика и scoped bridge работают.
- [ ] Версия `versionCode` уникальна, Android target API соответствует Play.
- [ ] Подписан релизным upload key; ключ не в ZIP и не опубликован в репозитории.
- [ ] Google Play: Data Safety, UGC/жалобы/блокировки, удаление аккаунта, платежи, политики/контакты соответствуют продукту.
