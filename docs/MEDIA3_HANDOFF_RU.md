# Медиа: браузер → Media3

До изменений `LeskovMediaService` показывал уведомление, но не владел реальным аудиодвижком. Теперь `LeskovNativeAudioService` содержит `ExoPlayer` / `MediaSession`, а `LeskovAudioHandoff` читает **играющий HTMLAudioElement** перед переходом и передаёт в нативный плеер URL, положение и метаданные. WebView останавливается, чтобы не конкурировать за AudioFocus. Мини-плеер появляется над навигацией. Новый веб-трек останавливает старое нативное воспроизведение.

Ограничения:

- Передача разрешена только для прямых URL `https://lesv.online/...`. `blob:`, media source, видео/WebRTC и другие хосты не захватываются.
- Редирект на CDN и Premium/DRM не интегрированы и **не должны** обходиться. В текущем клиенте токен доступа берётся из существующей сессии; перед продуктивным запуском необходимо протестировать redirects/auth и при необходимости построить серверный media endpoint с короткоживущим подписанным URL.
- Успешная подготовка ExoPlayer ещё **не проверена на устройстве**. Если загрузка аудиопотока не разрешена, возможен сбой воспроизведения; нужно логирование и серверная доработка.
- Не пытайтесь одновременно использовать веб-`mediaSession` и нативное Media3-событие над одним потоком.
