# Улучшения приложения и проверка выпуска

Изменения сохраняют существующий сайт и его серверные функции. Нативная оболочка доработана в следующих местах:

- Ошибка страницы больше не исчезает при событии progress=100 или onPageFinished. Повтор открывает исходный адрес, включая поисковый запрос и язык, вместо внутренней страницы ошибки Chromium.
- Отдельные состояния для недоступной сети, HTTP-ошибок сервера и недоверенного сертификата; тексты на RU/ET/EN. TLS-проверки остаются обязательными.
- История WebView сохраняется в состоянии Activity и восстанавливается после её пересоздания. Это не сохраняет содержимое незавершённых форм или аудиопоток после завершения процесса ОС.
- Подписи нижней навигации увеличены с 8.8 до 11 sp. На узком экране панель прокручивается, у каждого пункта не менее 64 dp ширины. Допускаются две строки и системное увеличение шрифта.
- Экран ошибки прокручивается при недостатке высоты.
- Видео WebView поддерживает нативный полноэкранный режим, скрытие системных панелей, выход кнопкой «Назад» и освобождение окна при закрытии Activity.
- Сбор состояния интерфейса учитывает жизненный цикл Activity. Ошибка чтения настроек ввода-вывода использует значения по умолчанию.
- Недоверенные адреса не могут менять состояние маршрута или адрес повторной загрузки. User-Agent использует реальную версию сборки.
- Добавлены регрессионные проверки ошибок/повтора/доверенных маршрутов. В CI включён существующий тест JS-контракта передачи аудио.

## Валидация

Локально выполнены tools/validate_source.py (60 проверок), tools/test_audio_snapshot.js и git diff --check. Локальная Android-сборка недоступна: отсутствуют Gradle и Android SDK. Запись через подключённый GitHub отклонена HTTP 403 Resource not accessible by integration. Pull request не создан, workflow не запущен. После загрузки исходников APK, Robolectric и lint необходимо проверить workflow android.yml.

## Условия финального выпуска

Успешная компиляция не подтверждает серверные сценарии. Для приёмки нужны реальная конфигурация Firebase, установленная серверная интеграция push, проверка доставки на закрытое приложение, два аккаунта и два устройства для звонков, воспроизведение при блокировке и смене сети, загрузка файлов, проверка App Links и подписанный владельцем release AAB. Эти сценарии в данной среде не подтверждены. Сайт просмотрен через подключённый браузер; серверный код сайта целиком в репозитории отсутствует.

На устройстве дополнительно проверить полноэкранное видео → Назад → предыдущая страница; узкий экран 320/360 dp и шрифт 200%; ошибку загрузки → повтор с сохранённым запросом; пересоздание Activity на странице поиска; музыку → переход → блокировку экрана. Публикация в магазине и изменения production-сервера этим PR не выполняются.
