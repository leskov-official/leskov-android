# LESKOV Android 3.4.3 — кандидат на релиз

Исходная версия из архива: Gradle 3.4.2 / versionCode 10, README 3.4.1. Новый номер выбран 3.4.3 / 11. Идентификатор приложения сохранён. Перед выпуском подтвердите, что код 11 больше всех ранее опубликованных кодов; если нет — согласованно измените Gradle, workflow, проверку релиза и документацию.

## Диалоги

В `messages.php` сайт отдаёт `data-active-user`, список диалогов, отдельные результаты друзей, `messageThread` и `messageComposer`. Предыдущая адаптация выделяла всю доступную высоту только списку диалогов, хотя поиск может показывать отдельный список друзей; зимний CSS задаёт конфликтующую геометрию. Новый стиль ограничивает страницу рамками WebView, прокручивает всю боковую панель и не принуждает скрытые результаты поиска к отображению. Переписка определяется по существованию thread/composer и выбранному пользователю. При тесном экране сохраняется возможность прокрутить основную панель до поля ввода; высота истории не падает ниже 96 CSS px. Нижняя панель Compose учитывает IME и системные отступы. Не меняет PHP-авторизацию, приватность сообщений или протокол звонков.

## Безопасность и Play Protect

Скриншот показывает блокировку вредоносного/поддельного приложения, а не только типовое предупреждение Chrome о скачивании APK. Точная причина неизвестна без самого APK, отчёта Google и проверки происхождения сборки. Отключите публикацию старого APK в админке. Не отключайте Play Protect и не меняйте package ID/сертификат для обхода блокировки.

Исходники и штатный CI не равнозначны проверке конкретного APK. Проверьте соответствие APK коммиту, сертификату, версиям, зависимостям, объединённому AndroidManifest, разрешениям и поведению сайта. Проведите антивирусный/динамический аудит и отправьте апелляцию Google, если подтверждён ошибочный результат: https://support.google.com/googleplay/android-developer/contact/protectappeals. При обнаружении угрозы — исправить её, повторить аудит и не публиковать до устранения.

Сборка на GitHub теперь имеет отдельный ручной workflow для подписанного кандидата. GitHub не выполняет гарантированную антивирусную проверку APK. Сертификат и SHA-256 не являются антивирусным отчётом. Указания по секретам см. README. Если предыдущие версии подписывались debug-ключом, обновление на правильно подписанный релизный APK может оказаться несовместимым; не обещать обновление поверх такой версии без проверки ключа. Приватные ключи не предоставлять третьим лицам.

## После сборки

1. Проверить логи GitHub Actions, тесты, lint, подпись, SHA-256 и исходный commit.
2. Выполнить приёмочный план на физических Android (включая Samsung, если доступен), с обычной навигацией и клавиатурой, без отключения защит.
3. Заполнить фактические результаты проверки безопасности с датой и ссылкой на отчёт. Если отчёта нет — не отмечать APK проверенным.
4. Только после прохождения проверки создать GitHub Release с тегом v3.4.3, приложить APK и SHA256SUMS; на сайт загрузить ровно тот же APK, версию 3.4.3, сверить автоматически вычисленный SHA-256 и затем включить публикацию.

## Границы этого патча

В архиве нет реального APK, signing key, Firebase-конфигурации и действующей сессии сайта. Локальные проверки Python/Node/PHP и Chromium проверяют исходники и изолированные сценарии. Полная Gradle-сборка, Android lint, проверка настоящего подписанного APK, FCM, Play Protect и физическое устройство требуют запуска в среде владельца. Удалённый GitHub не изменяется автоматически.
