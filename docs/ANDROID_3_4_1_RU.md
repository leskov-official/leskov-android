# Исправления 3.4.1 по скриншотам телефона

Скриншоты IMG_6330–6339 показали увеличенный веб-текст, обрезанные вкладки, лишнюю кнопку воспроизведения и неправильные размеры видеозвонка. Предыдущая проверка только гостевых страниц не покрывала эти сценарии.

## Изменения

- WebView textZoom снова 100%. Системный fontScale больше не умножает размеры сайта. Сохраняется ручное увеличение жестом; корневые CSS zoom/transform не применяются.
- Шесть равных вкладок размещаются без горизонтальной прокрутки: высота самой вкладки 50 dp, иконка 20 dp, компактная подпись. Масштаб подписи навигации ограничен 115%; полное название доступно TalkBack. Остальной нативный интерфейс сохраняет системный шрифт.
- Убраны дублирующий IME-padding и прежние общие инъекции, менявшие профили и ограничивавшие полноэкранные role=dialog размером карточки.
- CSS отдельно адаптирует заголовки, формы, таблицы настроек, основной Premium-плеер, входящий и активный звонок обоих движков. Полноэкранная подложка занимает весь WebView; прокручивается только карточка. Кнопки управления звонком переносятся внутри двух колонок.
- При переходе из Android-навигации вызывается реальный `__leskovNavigateWithPlayer` сайта. Тот же веб-аудиоэлемент, позиция, очередь и собственные контролы остаются в том же документе. Поддерживается собственная история сайта.
- Удалены LeskovNativeAudioService/Media3, передача аудио при Home/выборе файлов и добавленная кнопка внутри плеера. Android MediaSession управляет исходным веб-плеером и показывает системное уведомление, не воспроизводя второй поток.
- При показе звонка нижняя панель скрывается; навигация и Back защищают активный звонок от случайного уничтожения документа.
- Отменённый WebRTC PermissionRequest больше не используется после возврата системного диалога. BroadcastReceiver медиасервиса регистрируется с явным флагом; после завершения сервиса очищается его состояние, остановка не запускает новый сервис.

## Firebase

Проект `leskov-b3863`, Android package `com.aistudio.leskov.musix` совпадают с предоставленными скриншотами консоли и локальным google-services.json. Конфигурация APK остаётся приватной, GitHub Actions теперь отказывается собирать APK без неё.

На сервере при проверке 05.11.2026 присутствовало одно зарегистрированное устройство, последняя регистрация — 18:03:48. Ключ сервисного аккаунта серверной отправки отсутствовал. Наличие проекта в Firebase Console и google-services.json в APK не заменяет серверную авторизацию FCM HTTP v1.

- Кнопка `[data-notifications-push-enable]` в WebView повторно включается и вызывает нативный запрос разрешения/регистрацию FCM. Браузерный Web Push не запускается.
- Ответ регистрации разбирается как JSON. Устройство, отсутствие конфигурации APK, запрет Android, ошибка токена, необходимость входа и отсутствие серверного ключа различаются в интерфейсе.
- Серверный endpoint сохраняет устройство даже до подключения ключа и возвращает `delivery_ready`. Изменение применено к локальному серверу; PHP syntax проверен, неавторизованный запрос по-прежнему получает 401.
- Для отправки нужен JSON сервисного аккаунта проекта в `/etc/leskov/firebase-service-account.json` либо GOOGLE_APPLICATION_CREDENTIALS. Ключ не входит в приложение или GitHub. После его предоставления необходимо проверить OAuth/FCM v1 и доставку на реальном устройстве.

## Проверки

- Офлайн-тесты аудиомоста и app shell: источники, пауза, метаданные, перемотка, команды обоих плееров, переходы, защита звонка и включение нативной кнопки Push.
- Реальные `player.min.js` и `site.min.js` в Chromium с локальными WAV: play/pause/resume/seek/next; навигация из приложения и Back сохраняют **тот же документ и тот же продолжающий играть audio**. Добавленная кнопка отсутствует.
- Реальная разметка звонков из messages.php и includes/calls.php без персональных данных: 32 сочетания обоих движков, светлой/тёмной темы, портрета/альбомной ориентации. Кнопки не выходят за экран и не обрезают текст.
- В Android-тестах проверяется отображение всех шести вкладок на 320 dp при системном шрифте 200%, на русском и эстонском.
- CI: assembleDebug, Robolectric, lintDebug. Полный журнал и APK доступны в GitHub Actions для соответствующего коммита.

Повтор браузерных тестов: Playwright устанавливается вне проекта; NODE_PATH указывает на его node_modules.

```bash
NODE_PATH=/tmp/leskov-ui-check/node_modules node tools/check_premium_player.cjs
NODE_PATH=/tmp/leskov-ui-check/node_modules node tools/check_call_layout.cjs
NODE_PATH=/tmp/leskov-ui-check/node_modules node tools/check_mobile_layout.cjs
```

Прохождение сборки и браузерного стенда не доказывает отсутствие всех вылетов Samsung. Для точного подтверждения причины прежнего вылета нужен Android logcat. Проверки реального WebRTC между устройствами, проигрывания при блокировке и доставки FCM после подключения серверного ключа остаются отдельной приёмкой на телефоне.
